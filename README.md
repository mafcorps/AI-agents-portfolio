## Projects

### Agent 01 — AI Ad Copywriter

**Category:** Marketing & Advertising  
**Platform:** n8n  
**AI Integration:** Basic LLM Chain  
**Research Integration:** Tavily API

An AI-powered advertising assistant that generates marketing campaign content based on business information and product details.

**Key Features:**
- Researches businesses, products and competitors.
- Generates Meta Ads variations.
- Creates Google Ads variations.
- Defines target audiences and campaign angles.
- Suggests creative concepts for advertisements.
- Provides strategic marketing recommendations.

**Status:** Built and tested.
